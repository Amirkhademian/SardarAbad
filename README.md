# SardarAbad
The files contains files of SardarAbad digital twin project.
All files should be opened with Datamine RM Software.
The Topography folder contains files related to the quarry's topography.
The Orebody folder contains files related to the orebody of the deposit.
The Discontinuities folder contain files of modeled discontinuities.
The Block Model Azimuth 0 contains the resulted blocking layout in azimuth of 0.
